# Raw GLATOS Workbook from St. Marys River Sea Lamprey project

A completed GLATOS workbook from St. Marys River Sea Lamprey project.

## Format

A macro-enabled Microsoft Excel workbook file (\*.xlsm) with six
worksheets:

- project:

  project code, principal investigator and contact

- locations:

  descriptions of receiver array locations

- proposed:

  proposed receiver deployment locations and dates

- deployment:

  receiver deployment data (what, where, when, how)

- recovery:

  receiver recovery data (what, where, when, how)

- tagging:

  animal collection, tagging, and recovery data
