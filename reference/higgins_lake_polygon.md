# An sf POLYGON object with coastline of Higgins Lake

An sf POLYGON object with coastline of Higgins Lake, Michigan. Used as
an example of a polygon representing a water body.

## Usage

``` r
higgins_lake_polygon
```

## Format

An object of class `sf` (inherits from `data.frame`) with 1 rows and 2
columns.
