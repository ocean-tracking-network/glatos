# Video frames of walleye movements in Lake Huron

Sequential images of walleye movements in Lake Huron for testing
functionality of ffmpeg function.

## Format

Folder contains 30 sequentially labeled .png image files

## Source

<https://glatos.org/home/project/HECWL>

## Filename

frames

## Author

Todd Hayden

## Examples

``` r
system.file("extdata", "frames", package = "glatos")
#> [1] "/home/runner/work/_temp/Library/glatos/extdata/frames"
```
