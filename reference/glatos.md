# glatos: A package for the Great Lakes Acoustic Telemetry Observation System

Functions useful to members of the Great Lakes Acoustic Telemetry
Observation System https://glatos.org; many more broadly relevant to
simulating, processing, analysing, and visualizing acoustic telemetry
data.
