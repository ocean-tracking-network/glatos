# An sf POLYGON object with coastline of Flynn Island

An sf POLYGON object with coastline of Flynn Island; and island within
Higgins Lake, Michigan. Used as an example of a polygon representing a
body of land (as opposed to water body).

## Usage

``` r
flynn_island_polygon
```

## Format

An object of class `sf` (inherits from `data.frame`) with 1 rows and 2
columns.
